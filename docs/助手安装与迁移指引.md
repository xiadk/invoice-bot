# 本机助手（1688催收助手）安装与迁移指引

> 版本：2026-10-14 ｜ 适用：Windows 10 / 11（x64）
> 一句话：**发送从「浏览器扩展」迁移到「本机桌面助手」**。登录态仍只在你本机，服务器不代发；绑定不再用税号，改用一次性令牌换取的**设备令牌**。

---

## 1 为什么要迁移

| 维度 | 旧：浏览器扩展 | 新：本机助手（Electron 桌面程序） |
| --- | --- | --- |
| 安装 | 开发者模式「加载已解压的扩展程序」（小白 5+ 步） | 双击 `.exe` 安装 / 绿色版直接运行 |
| 上架/合规 | 扩展商店明确禁止「自动代发消息（Bots）」，上架风险高 | 桌面程序**不受浏览器商店政策约束** |
| 连接 | 手填「服务器地址 + 税号（配对码）」 | 看板「绑定本机助手」→ 深链 `xsh://bind` 自动绑定 |
| 凭据 | 税号当配对码（半公开、可被冒用） | 一次性绑定令牌 → 本机长期**设备令牌**，服务器只存 SHA-256 |
| 保活 | MV3 Service Worker 会被回收，需 alarms 续命 | 常驻托盘，`setInterval` 稳定心跳 |
| 登录态 | 你本机浏览器（不上服务器） | 助手内置浏览器（不上服务器）——**这一点不变** |

**核心红线未变**：服务器**不保存**你的 1688 登录态、**不代发**消息；发送只发生在你自己电脑上、用你自己的真实 IP。

## 2 普通用户：三步用起来

### 步骤 1 · 下载安装（一次）
1. 在浏览器打开看板 → 右上角「**本机助手**」→ 弹窗里点「**下载本机助手（Windows）**」，或直接访问 `http://<服务器地址>/download`。
2. 运行下载到的 `.exe`：安装版按向导「下一步」；绿色版双击即启动。
3. 首次运行如提示「**未知发布者**」（未签名程序的常规提示，非病毒）→ 点「**更多信息 → 仍要运行**」；若被 360/火绒拦截 → 选择「允许/信任」。

启动后助手常驻**系统托盘**（右下角图标），右键可打开状态面板 / 退出。

### 步骤 2 · 绑定（一次）
1. 回看板 → 右上角「**本机助手**」→ 点「**绑定本机助手**」。
2. 浏览器弹出「是否打开 **1688催收助手**」→ 点「**打开**」。
3. 助手用一次性令牌自动换取本机设备令牌，看板显示「**助手已连接**」即成功。

> 不需要手填服务器地址或税号。若点「绑定」没反应：确认已安装助手；并留意浏览器地址栏右侧出现的「打开 1688催收助手」小图标，点它并「允许」。

### 步骤 3 · 登录 1688（一次）
在助手面板（或看板弹窗）点「**打开 1688 登录页**」→ 在打开的窗口里正常登录。登录态只存本机。

之后：看板勾选卖家 → 点「发送催收消息」→ 若助手没开，看板会用 `xsh://run` 自动唤起 → 消息逐家发出，断线可续跑（已成功的不重发）。

## 3 管理员/部署方：让下载与绑定可用

1. **构建安装包**（在有网络、能下载 Electron 的机器上）：
   ```bash
   npm install                 # 安装依赖（含 electron / electron-builder）
   npm run agent:dist          # 生成 nsis 安装版 + portable 绿色版，输出到 dist/
   # 或分别： npm run agent:dist:nsis  /  npm run agent:dist:portable
   ```
   产物体积约 **150–250 MB**（内含 Chromium），`artifactName` 形如 `1688催收助手-0.1.0-x64.exe`。
2. **放置产物**：把 `dist/*.exe` 留在服务器项目的 `dist/` 目录（该目录已在 `.gitignore` 中排除，不入库）。
3. **配置服务器地址**（看板「系统管理 → 本机助手」填「服务器地址」，或 `config.json` 的 `server_url`）：
   - 该地址会被写入 `server_url`，看板据此拼接绑定深链与安装包地址。
   - 未配置时，绑定仍可用「看板当前访问地址」自动纠正。
4. **验证**：浏览器访问 `http://<地址>/download` → 页面应显示可点击的「下载 1688催收助手（Windows）」按钮（对应 `GET /api/agent/download-exe`）。
   - 若显示「安装包尚未就绪」，说明 `dist/` 下没有 `.exe`，回到第 1 步构建。

> `dist/` 无 `.exe` 时，`/api/agent/download-exe` 返回 404 + 友好提示；`/api/agent/channel-info` 返回 `agentDownload.available=false`，下载页据此降级提示。

## 4 从旧浏览器扩展迁移

| 你当前的状态 | 要做的事 |
| --- | --- |
| 还在用扩展（开发者模式加载） | 下载安装助手 → 看板「绑定本机助手」→ 登录 1688 → 之后即可停用扩展 |
| 存有旧的 `extension/` 目录或 `invoice-bot-extension.zip` | 可删除。旧扩展下载接口已下线（返回 **410 Gone**，并提示迁移到 `/download`） |
| 书签工具（零安装）用户 | 可继续用（`/bookmarklet`），但功能与稳定性弱于助手；建议迁移 |

**已下线的旧接口**（调用会返回 410）：
- `GET /api/agent/extension-download`
- `GET /api/agent/my-extension-download`

**绑定模型变更（重要）**：
- ❌ 旧：连接参数 `?code=<税号>`（税号即配对码，永不过期、可被冒用）。
- ✅ 新：看板签发一次性绑定令牌（120 秒）→ 助手深链换取**设备令牌**（64 位十六进制）→ 以 `?device=<设备令牌>` 连接。
- 服务器只在 `agent_device` 表保存 `token_hash = sha256(设备令牌)`，**不存明文**。
- 可在看板查看已绑定设备并**撤销**（撤销会立即断开该设备在线连接）。

> 兼容：`/ws/agent` 同时接受 `?device=` 与旧参数名 `?code=`，但**值必须是设备令牌**；传入税号一律拒绝。

## 5 安全与隐私

- **登录凭据不出本机**：1688 登录态只存在助手自带的浏览器 profile 里（`persist:1688`），服务器全程接触不到账号密码。
- **设备令牌可撤销**：令牌只有本机保存；服务器存哈希。设备丢失/换机 → 看板撤销旧设备即可。
- **发送用你的真实 IP**：助手在你自己电脑上操作，不用机房 IP，规避平台对云 IP 段的风控；消息间隔由看板的「卖家间隔秒数」控制（默认 20–35 秒随机）。
- **安装包未签名**：MVP 阶段不买代码签名证书，会出现 SmartScreen「未知发布者」提示；正式发售前建议购买 OV/EV 证书或 Azure Trusted Signing 消除提示。

## 6 常见问题（排障）

| 现象 | 原因 / 处理 |
| --- | --- |
| 点「绑定本机助手」无反应 | 未安装助手，或浏览器拦截了 `xsh://` 打开请求 → 先装助手；地址栏右侧点「打开 1688催收助手」并允许 |
| 看板状态条灰、发送无反应 | 助手未启动 → 点右上角「本机助手」按指引启动；或点发送由看板自动 `xsh://run` 唤起 |
| 发送报「本机助手未连接」 | 助手掉线（被关/网络断）→ 从托盘重新打开助手，看板会自动重连（设备令牌有效，无需重新绑定） |
| 首次运行被拦截/提示未知发布者 | 未签名导致 → 「更多信息→仍要运行」；杀软加白名单 |
| 下载页显示「安装包尚未就绪」 | 管理员未构建 → 在服务器执行 `npm run agent:dist`，把 `dist/*.exe` 放到 `dist/` |
| 发到一半中断 | 重新打开助手 → 看板出现「上次任务已中断」横幅 → 点「继续发送未完成」续跑，已成功的不重发 |

## 7 相关文件与端点

**代码**
- 助手主进程：`electron/main.js`（单实例锁、`xsh://` 注册、托盘、深链处理）
- 发送内核：`electron/agent/sender.js`（独立 `persist:1688` 窗口 + UA 伪装 + 子 iframe 定位）
- 页面注入：`electron/agent/inject-page.js`（移植自 `extension/content.js` 的 DOM 发送逻辑）
- 连接客户端：`electron/agent/ws-client.js`（移植自 `extension/background.js`）
- 本地存储：`electron/store.js`（`<userData>/agent.json`，设备令牌）
- 看板/下载页：`dashboard.html`、`download.html`、`bookmarklet.html`
- 服务端：`server.js`、`lib/agent-hub.js`、`sql/schema.sql`（`agent_device` 表）

**HTTP 端点**
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/agent/channel-info` | 返回 `serverUrl` + `agentDownload{available,url,fileName,sizeBytes}` |
| GET | `/api/agent/download-exe` | 下载 `dist/` 下最新安装包（未构建则 404） |
| POST | `/api/agent/pair-code` | 需登录；签发一次性绑定令牌 + `xsh://bind` 深链 |
| POST | `/api/agent/bind` | **公开**（靠绑定令牌鉴权）；换长期设备令牌 |
| GET | `/api/agent/status` | 在线状态（看板轮询） |
| GET | `/api/agent/devices` | 已绑定设备列表 |
| POST | `/api/agent/devices/revoke` | 撤销设备（并断开在线连接） |
| POST | `/api/agent/disconnect` | 断开当前连接（保留设备令牌） |
| WS | `/ws/agent?device=<设备令牌>` | 助手长连接（`ready`/`send_batch`/`task_progress`/`client_stop`） |

**自定义协议**：`xsh://bind?server=<url>&t=<绑定令牌>`（绑定）、`xsh://run`（唤起发送）。注册在 HKCU（免管理员）。
