# 新用户上手指南

> 一句话：**账号由管理员开通 → 你登录 → 在你自己浏览器登录 1688 并用扩展把登录态传上来 → 把自己的订单/发票 Excel 导进来 → 名称映射对齐 → 看板一键催收。**
> 全流程 6 步，首次大约 20~30 分钟，之后每天只用到第 5 步。

---

## 0 先搞清楚角色

| 角色 | 能看什么 | 能做什么 |
|---|---|---|
| **超级管理员** `admin` | 看板 + 名称映射 + **系统管理** | 建账号、**按账号维护开票抬头**、重置密码、禁用/删除用户、查看业务账号的看板（只读）、改全局参数与话术。<br>**admin 是纯系统账号**：不承载看板数据、不维护抬头，用户列表里只有「重置密码」 |
| **普通用户**（你） | 只有**自己的**看板 + 名称映射 | 导入自己的数据、维护映射、发送催收。看不到「系统管理」，也看不到别人的数据 |

- 数据按账号隔离：业务表都带 `user_id`，你的数据目录是服务器上的 `data/users/<你的ID>/`。
- 普通用户**没有注册入口**，必须由管理员先建号。

---

## 前提：管理员开通账号

管理员登录后进入「**系统管理 → 用户管理**」，点「新增用户」，填写：

| 字段 | 说明 |
|---|---|
| 公司全称（= 登录账号） | **登录账号就是公司全称**（开票抬头公司名），会带进催收话术。2~64 位，可用中文、字母、数字、下划线、点、中划线、括号 |
| 初始密码 | ≥4 位（用户拿到后可在自己的账号设置里改） |
| 纳税人识别号 | 抬头税号 |
| 收票邮箱 | 催收话术里给商家的收票邮箱 |

> **开票抬头属于用户信息**，统一在「系统管理 → 用户管理」里按账号维护：点某行的「编辑」即可改公司全称 / 税号 / 收票邮箱。
> 由于账号=公司全称，**改公司全称会同时改掉该账号的登录名**（改完要用新名字登录）。`admin` 是内置账号，账号名固定、不参与改名。

创建成功后**系统会自动为该用户建好独立数据目录**（`data/users/<ID>/完成订单`、`已开票订单`），用户即可登录。

> 管理员首页的 `admin / admin` 是部署时内置的，**请立即改密**。停用某个账号时，该用户已登录的会话会被立刻踢下线。

## 1 登录

浏览器打开系统地址（本机默认 `http://localhost:8787`，云端是部署域名）→ 自动进入登录页 `/login`。

- 输入管理员给你的**公司全称（= 登录账号）+ 密码** → 登录。
- 登录页**只有登录、没有注册**。
- 未登录或登录态过期时，访问任何页面都会**自动跳回登录页**；登录态用 HttpOnly Cookie 保存，改密/停用后旧会话立即失效。

---

## 2 首次登录：连上你的 1688（只做一次）

系统发催收消息时要借用你的 1688 登录态。看板检测到你还没登录时，**会自动弹出「登录 1688」引导弹窗**（也可随时点右上角「登录 1688」打开）。

**登录在你自己电脑的浏览器里完成，服务器接触不到你的账号密码**：

1. 先在你自己的浏览器里打开 **1688** 并确认已登录（通常你本来就登录着）。
2. 安装扩展：Chrome / Edge → `chrome://extensions` → 开「开发者模式」→「加载已解压的扩展程序」→ 选项目里的 `extension/` 目录。
3. 看板弹窗点「**生成上传码**」→ 记下 **服务器地址 + 6 位上传码**（10 分钟有效、**用一次即作废**）。
4. 点扩展图标 → 「方式二：上传登录态给服务器」→ 填服务器地址 + 上传码 → 点「**上传登录态**」。
5. 回弹窗点「**刷新状态**」→ 显示「**可用**」即完成。

之后每次进看板若提示需登录，重复第 3~5 步即可。登录态通常能维持数天到数周。

> 登录态以 **AES-256-GCM 密文**存在数据库中（`login_state` 表），**接口不下发明文、只在你的任务里复用**，其他用户看不到。想换账号点弹窗里的「清除登录态」。

---

## 3 放进你自己的数据并导入

系统**没有上传按钮**——数据文件由**部署方/管理员**放到你这台服务器上的专属目录里：

| 目录 | 放什么 | 怎么导出 |
|---|---|---|
| `data/users/<你的ID>/完成订单/` | 1688 订单列表 `.xlsx` | 1688「已买到的货品」→ 筛选**交易成功** → 导出 |
| `data/users/<你的ID>/已开票订单/` | 税务局历史发票 `.xlsx` | 电子税务局「**全量发票查询**」→ 导出 |

放好后，在看板点「**重新导入数据**」。它会：

- 重新扫描这两个目录，**全量重建**你的订单表与已开票表；
- 保留**人工维护的名称映射**与**人工确认的开票状态**（不会被覆盖）。

> 建议每周更新一次：导出新文件覆盖旧文件，再点一次「重新导入数据」。

---

## 4 维护名称映射（决定统计准不准）

税务局发票里写的是**销方名称**，1688 订单里写的是**商家名称**，两边写法常常不一样。对不上，看板就把发票金额统计不到对应商家。

进「**名称映射**」页：

| 区域 | 你要做的 |
|---|---|
| **待人工比对** | 自动匹配不上的销方名称列在这里，右侧输入对应的 1688 公司名（有下拉提示）→「保存」 |
| **忽略** | 若某个销方名称**确认没有**对应的 1688 商家，点「忽略」，它不再参与统计 |
| **已维护映射** | 查看/删除已建立的映射 |
| **已忽略** | 误忽略的点「恢复」找回 |

自动匹配顺序：名称完全一致 → 名称互相包含 → 卖家会员名匹配 → 发票备注里的店铺名线索。

> 提示：看板顶部「**未匹配销方名称数**」降到 0，说明映射齐了。

---

## 5 日常：在看板发催收（每天只用这一步）

进「**看板**」页。**一行 = 一家公司**，点「展开会员名(N)」能看到这家公司名下的各个 1688 店铺，每个店铺各有订单、金额、开票状态和催收按钮。

常用操作：

| 你想做的 | 怎么做 |
|---|---|
| 找到该催的账 | 用「催收状态」（已催收 / 最近一周、半月、一月、三月**未催收**）+「开票状态」（已开票 / 未开票）+ 搜索（公司名 / 会员名）**任意组合**筛选 |
| 催一家店 | 点该店铺的**橙色「催收消息」**按钮 → 发出 3 条（模板 + 订单清单 + 提醒），催收次数 +1 |
| 批量催收 | 勾选会员名（公司行的复选框会带出该公司全部可催收店铺）→ 顶部「**发送催收消息 (N)**」 |
| 看进度 | 顶部进度条实时显示「已完成/总数 · 当前卖家 · 成功/失败 · 已用时长 · 预计剩余」，可随时「停止」 |
| 核对历史 | 点「催收次数」看历史：时间 / 结果 / 金额 / 订单号 / 失败原因 |
| 商家线下一次性开票 | 展开订单明细 → 点「**全部标记已开票(N)**」（人工确认，不会被平台刷新覆盖） |

**按钮什么时候可用**：该店铺有**待开票金额** **且** 还有未开票订单 **且** 有卖家会员名。全部开票后按钮自动置灰。

**催收口径（按会员名，不串店）**：`{amount}` = 该店铺自己的待开票金额；`{orderId}` = 该店铺除「已开票」外的全部订单号。每个店铺只收到自己店里的账。

## 5b 可选：改用「本机浏览器通道」发送

默认用**服务器浏览器**发送。若不想把 1688 登录态交给服务器，或想用**自己本机 IP** 发送，切到**本机浏览器通道**（方案C）：消息由你自己电脑的浏览器发出，服务器只派任务、记结果，拿不到你的账号密码。

1. 看板点「**生成配对码**」，复制弹出的**服务器地址 + 6 位配对码**（5 分钟有效）。
2. 自己浏览器：`chrome://extensions` → 开「开发者模式」→「加载已解压的扩展程序」→ 选项目 `extension/` 目录。
3. 点扩展图标，填「服务器地址 + 配对码」→「连接」；再点「打开登录页」登录 1688。
4. 看板顶部状态条变绿（「已连接 · 1688 已登录」）后，把发送通道切到「**本机浏览器**」→ 勾选卖家 → 发送。

> 兼容性：仅桌面 **Chrome / Edge**。360 极速模式、IE、手机浏览器**不支持**。
> 发送中要保持该浏览器开着；关掉会中断任务。

**断线续跑**：发到一半断线（关浏览器 / 服务重启）后，重新连上，看板会出现黄色横幅「↻ 上次任务 #N 已中断：还有 X 家未发送」→ 点「**继续发送未完成**」接着发，**已成功的不重发**；「**重试失败项**」只补失败的那几家；不想处理点「忽略」。

---

## 6 发送前先核对（可选）

不想真发就想看内容：

```bash
npm run msg:preview -- 会员名1 会员名2
```

会用看板真实数据 + `config.json` 模板，渲染出**将要发送的每条消息**，并对照 `{amount}` 与订单实付合计。不联网、不发送。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 打开就跳到登录页 | 未登录或登录态过期 → 正常重新登录 |
| 看板提示需登录 1688 / 发送报「mtop 未就绪」 | 1688 登录态失效 → 在你自己浏览器确认已登录 1688，再走「生成上传码 → 扩展上传登录态 → 刷新状态」 |
| 上传登录态时提示「本机没有找到 1688 登录态」 | 你浏览器里当时没登录 1688 → 打开 1688 登录后再点「上传登录态」 |
| 上传成功但看板仍显示需登录 | 弹窗里点「刷新状态」；若显示「已失效」，说明上传时浏览器已掉线，重新登录后重传 |
| 看板是空的 | 还没导入数据 → 确认 Excel 已放到 `data/users/<你的ID>/` 下，再点「重新导入数据」 |
| 已开票金额不对 / 少了 | 销方名称没映射 → 去「名称映射」页处理「待人工比对」 |
| 催收按钮灰色 | 该店铺已无待开票金额或无未开票订单（悬停有原因提示） |
| 看不到「系统管理」 | 你是普通用户，这是正常的（仅超级管理员可见） |
