# 1688 发票催收 · 本机发送助手（Chrome/Edge 扩展）

方案C 的客户端。**在您自己的浏览器里**完成 1688 催收消息发送：服务器只下发任务、记录结果；
1688 登录态与密码不会离开本机。

## 安装（加载已解压的扩展程序）

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」→ 选择本目录 `extension/`
4. 在浏览器工具栏点扩展图标，填入：
   - **服务器地址**：如 `http://your-server:8787`（云部署填 `https://你的域名`）
   - **配对码**：在看板「本机浏览器通道」面板点「生成配对码」得到（6 位，5 分钟内有效）
5. 点「连接」。状态显示「已连接服务器」即成功。

## 使用前

- 请先在当前浏览器**登录 1688**（扩展里点「打开登录页」）。登录态留在本机浏览器。
- 保持浏览器运行；关闭浏览器后本机通道离线，任务无法执行（可稍后重连再发）。

## 工作原理

1. 看板点「发送」并选择「本机浏览器通道」→ 服务器把任务通过 WebSocket 下发给扩展
2. 扩展打开一个工作标签页，逐个卖家导航到 1688 聊天页
3. `content.js` 在该页内输入并点击发送，验证消息出现在聊天记录后回执
4. 服务器把结果写入 `send_log`（金额/订单号/失败原因），看板展示进度

## 权限说明

| 权限 | 用途 |
|---|---|
| `*.1688.com` | 在 1688 聊天页执行发送 |
| `*://*/*` | 连接您填写的服务器地址（WebSocket）；可收窄为你的服务器域名 |
| `storage` | 保存服务器地址、配对码、登录态标记 |
| `tabs` | 打开并驱动工作标签页 |
| `alarms` | 定时保活重连 |

**不读取 Cookie、不上传任何凭据**；只上报「是否已登录 1688」这一布尔值。

## 兼容性

| 浏览器 | 支持 |
|---|---|
| Chrome / Edge（桌面） | ✅ 推荐 |
| Firefox | ⚠️ 需改 manifest（`background.scripts`）并签名分发 |
| 360 极速模式 | ⚠️ 不保证 |
| 360 兼容模式 / IE | ❌ 无现代扩展体系 |
