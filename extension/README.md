# 1688 发票催收 · 本机发送助手（Chrome/Edge 扩展）

一个扩展，两种用法（可只用其中一种）：

| 用法 | 说明 | 登录态在哪 |
|---|---|---|
| **① 本机浏览器直接发送**（方案C） | 消息由**您自己的浏览器**发出；服务器只派任务、记结果 | 不出本机 |
| **② 上传登录态给服务器**（服务器通道代发） | 在您本机登录 1688 后，把登录态**加密上传**给服务器，由部署机器上的浏览器代发 | 加密存服务器数据库 |

两种情况**密码都不会离开本机**：扩展不读密码，上传的只是浏览器本来就会发的 cookie。

---

## 安装（加载已解压的扩展程序）

**方式 A（推荐，普通用户）**：从本系统下载已内置服务器地址 + 你的税号的专属扩展包
- 入口一（公开页，无需进后台）：直接访问 `http://<服务器地址>/download` 下载页，登录后点「下载我的专属扩展」即可
- 入口二（后台）：登录本系统 → 进入「**系统管理**」页 → 点「**下载浏览器扩展（.zip）**」
1. 解压压缩包，得到 `extension/` 目录
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」→ 选择刚解压的 `extension/` 目录
4. 在浏览器工具栏点扩展图标 → **服务器地址与税号都已预填**，直接点「**连接**」即可

**方式 B（开发人员 / 自行打包）**：直接用仓库里的 `extension/` 目录
1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」→ 选择本目录 `extension/`
4. 在浏览器工具栏点扩展图标

## 用法 ①：本机浏览器直接发送（方案C）

1. 从下载页 `/download` 下载你的**专属扩展包**（已内置服务器地址与税号）并安装
   - 专属包里的税号就是该账号在「系统管理 → 用户管理」里维护的**纳税人识别号（税号）**，**固定且永不过期**，断线重连无需重新下载，服务器重启也不影响
   - 服务器地址由超级管理员在「系统管理 → 本机通道」统一配置；管理员改地址后，用户重新下载一次扩展即可生效
2. 打开扩展弹窗，服务器地址与税号都已预填，直接点「**连接**」，状态显示「已连接服务器」即成功
3. 点「**打开登录页**」在**当前浏览器**登录 1688（登录态留在本机）
4. 看板把发送「通道」切到「**本机浏览器**」→ 勾选卖家 → 发送

> 保持浏览器运行；关闭浏览器后本机通道离线，任务无法执行（可稍后重连再发）。

## 用法 ②：上传登录态给服务器（服务器通道代发）

1. 先确认**当前浏览器已登录 1688**（可直接点扩展里「打开登录页」，并让该标签页保持打开）
2. 看板右上角点「**登录 1688**」→ 点「**生成上传码**」→ 记下**服务器地址 + 6 位上传码**（10 分钟有效、**用一次即作废**）
3. 扩展弹窗「方式二：上传登录态给服务器」里填**服务器地址 + 上传码** → 点「**上传登录态**」
4. 回到看板点「**刷新状态**」→ 显示「**可用**」即完成

上传内容 = 本机 `1688.com` 的 **cookie（含 httpOnly）** + 已打开的 1688 页面 `localStorage`（组装成 Playwright `storageState`）。

## 工作原理

**用法 ①（本机发送）**
1. 看板点「发送」并选择「本机浏览器通道」→ 服务器把任务通过 WebSocket 下发给扩展
2. 扩展打开一个工作标签页，逐个卖家导航到 1688 聊天页
3. `content.js` 在该页内输入并点击发送，验证消息出现在聊天记录后回执
4. 服务器把结果写入 `send_log`（金额/订单号/失败原因），看板展示进度

**用法 ②（上传登录态）**
1. 扩展 `chrome.cookies.getAll({domain:'1688.com'})` 取 cookie，`chrome.scripting.executeScript` 取 `localStorage`
2. `POST {服务器地址}/api/state/upload`，带上一次性上传码
3. 服务器用 **AES-256-GCM** 加密后写入数据库 `login_state`；接口永远不会把密文明文返回给任何前端

## 权限说明

| 权限 | 用途 |
|---|---|
| `*://*.1688.com/*` | 在 1688 聊天页执行发送；读取该站的 cookie / localStorage 用于上传登录态 |
| `*://*/*` | 连接您填写的服务器地址（WebSocket / HTTPS）；可收窄为你的服务器域名 |
| `storage` | 保存纳税人识别号（税号）、登录态标记与上次上传结果（服务器地址由打包时内置，一般不落 storage） |
| `tabs` | 打开并驱动工作标签页 |
| `alarms` | 定时保活重连 |
| `cookies` | **仅用法 ②**：读取 1688 的 cookie 以供上传（不读取其它网站） |
| `scripting` | **仅用法 ②**：在已打开的 1688 标签页里读 `localStorage` |

**不读取密码、不上报密码**；用法 ① 只上报「是否已登录 1688」这一布尔值；用法 ② 仅在您点「上传登录态」时**主动**发送一次，且只发给您自己填的服务器地址。

## 兼容性

| 浏览器 | 支持 |
|---|---|
| Chrome / Edge（桌面） | ✅ 推荐 |
| Firefox | ⚠️ 需改 manifest（`background.scripts`）并签名分发 |
| 360 极速模式 | ⚠️ 不保证 |
| 360 兼容模式 / IE | ❌ 无现代扩展体系 |
